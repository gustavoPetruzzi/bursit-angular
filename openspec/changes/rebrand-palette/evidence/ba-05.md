## Why the dark render is forced this way

The landing has **no theme script**: the built render contains **0 `<script>` tags**, and
`bursit-theme` appears in the source only inside documentation copy (`ThemeSection.astro:72,112,115`,
`ComponentsGrid.astro:126`) — never as an attribute and never from `documentElement`. There is no
`prefers-color-scheme` rule in `global.scss`. Dark mode can therefore only be produced by putting
`bursit-theme="dark"` on `<html>`.

The built stylesheet the render loads (`landing/dist/_astro/index.BaS2y8rc.css`, 64 681 bytes)
contains the dark layer, so forcing the attribute genuinely switches the cascade:
`[bursit-theme=dark]` present; `.dark` present; dark `--color-primary` `#e8a1af` ×7; dark
`--color-secondary` `#7ba3cc` ×4; dark `--color-bg` `#22282e` ×13.
